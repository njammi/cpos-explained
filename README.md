# CPOS — explained

A short, public explainer for **CPOS (Claude Project Operating System)** — a personal governance standard for running many AI-assisted projects at once without losing consistency between them.

This is a static, single-page site. No build step — `index.html` is the whole thing.

**Live site:** https://njammi.github.io/cpos-explained/

## What this is not

This isn't a product, a template repo to install, or a claim about how anyone else should run their projects. It documents one person's working system, including real (anonymized) numbers from the portfolio it currently governs.
